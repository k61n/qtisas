====== QtiSAS Graph / GraphWindow Python API ======

Python scripting interface for 2D plots.\\
''GraphWindow'' — the multi-layer window (SIP name for ''MultiLayer'')\\
''Graph'' — one plot panel inside a ''GraphWindow''

<note>All SIP-wrapped methods accept positional arguments. Named optional parameters also accept keyword syntax; required parameters are always positional.</note>

<note tip>**Defaults:** Every new layer has user Preferences (fonts, tick style, backbone, canvas frame, antialiasing, axis visibility) auto-applied. Do not re-set these unless explicitly required — only call ''setAxisFont'', ''setTitleFont'', ''setAxesLinewidth'', ''drawAxesBackbones'', etc. when overriding the default.</note>

<note tip>**Qt classes (''QColor'', ''QFont'', ''QPen''):** Use only when no native QtiSAS method exists. Prefer ''colorIndex("name")→int'' for curve colours and ''symbolIndex("name")→int'' for curve symbols. Use ''QColor'' only when a method explicitly requires it (e.g. ''addErrorBars'' color argument, ''setCanvasColor'').</note>

===== Quick Start =====

<code python>
# plot two columns from a table
t = table("Data")
gw = plot(t, ("x", "y"), Graph.CurveType.Line)

g = gw.activeLayer()
g.setXTitle("q, 1/nm")
g.setYTitle("I(q)")
g.setScale(Graph.Axis.Bottom, 0.01, 1.0, 0, 5, 5, Graph.Scale.Log10)
g.setScale(Graph.Axis.Left,   1e-3, 1e3, 0, 5, 5, Graph.Scale.Log10)
g.replot()
</code>

<code python>
# create an empty 2-panel window (1 row, 2 cols) and fill each panel
gw = newGraph("MyPlot", 2, 1, 2)      # 2 panels, 1 row, 2 cols
g1 = gw.layer(1)
g2 = gw.layer(2)

t = table("Data")
g1.addCurve(t, "I", Graph.CurveType.Line)
g2.addCurve(t, "dI", Graph.CurveType.Scatter)
</code>

<note tip>**Stacked panels — zero canvas gap** (e.g. data+fit / residuals) — always use this pattern:
<code python>
g = newGraph("SANS_Fit", 2, 2, 1)
l1 = g.layer(1); l2 = g.layer(2)
l1.enableAxis(Graph.Axis.Bottom, False)   # disable seam axes BEFORE arrangeLayers
l2.enableAxis(Graph.Axis.Top,    False)
g.setAlignPolicy(GraphWindow.AlignPolicy.AlignCanvases)  # REQUIRED — same X, same width, canvas gap
g.setSpacing(0, 0)                                       # canvas-to-canvas gap = 0
g.arrangeLayers(False, False)
# set titles/scales/curves AFTER arrangeLayers
# X title only on l2 — l1 bottom axis disabled, setXTitle on l1 has no effect
</code></note>

==== Curve symbols ====

<note important>NEVER manipulate symbols via ''QwtSymbol'' or ''dataCurve(curve(...)).setSymbol(...)'' — ''QwtSymbol'' is not exported and ''dataCurve(int)'' takes an index, not a ''PlotCurve'' object. Use the Graph methods below.</note>

^ Method ^ Notes ^
| ''setCurveSymbolColor(index, colorIndex|QColor)'' | fill / brush colour |
| ''setCurveSymbolBorderColor(index, colorIndex|QColor)'' | border / pen colour |

| ''setCurveSymbolStyle(index, int)'' | shape — use ''symbolIndex("name")'' for lookup |

<code python>

</code>

==== Error bars ====

^ Method ^ Returns ^ Notes ^
| ''addErrorBars("curveName", t, col, type=1, w=1, cap=8, color=QColor, ...)'' | ''ErrorBarsCurve'' | attach by curve name |
| ''addErrorBars(dataCurve, t, col, type=1, w=1, cap=8, color=QColor, ...)'' | ''ErrorBarsCurve'' | attach to ''DataCurve'' object |

  * ''type'': ''0'' = X errors, ''1'' = Y errors (default)
  * ''color'': ''QColor'' — **not** ''colorIndex()''

  * ''minus'': draw the lower (−) bar — must be ''True'' to show any bar
  * ''plus'': draw the upper (+) bar — must be ''True'' to show any bar
  * **(False, False, False) = invisible** — no bars rendered at all

<code python>

# full style with through-line (default):

</code>

===== Constants quick reference =====

Sub-namespace objects are attached to the ''Graph'' type at module load time. Both ''Graph.Axis.Bottom'' and the flat ''Graph.Bottom'' resolve to the same integer — use whichever you prefer.

<code python>
# Graph.Axis      Left=0  Right=1  Bottom=2  Top=3
# Graph.Scale     Linear=0  Log10=1  Ln=2  Log2=3  Reciprocal=4  Probability=5  Logit=6
# Graph.Ticks     NoTicks=0  Out=1  InOut=2  In=3
# Graph.CurveType Line=0  Scatter=1  LineSymbols=2  VerticalBars=3  Area=4  Pie=5 …
</code>

===== Full example =====

<code python>
t = newTable("SANS", 50, 3)
t.setColNames(["q", "I", "dI"])
# ... fill data ...

gw = newGraph("SANS_plot")
g = gw.activeLayer()

g.addCurve(t, "I", Graph.CurveType.LineSymbols)
g.addErrorBars("SANS_I", t, "dI", 1, 1, 8)

g.setXTitle("q, 1/nm")
g.setYTitle("I(q), 1/cm")
g.setScale(Graph.Axis.Bottom, 0.01, 1.0, 0, 5, 5, Graph.Scale.Log10)
g.setScale(Graph.Axis.Left,   1e-3, 1e3, 0, 5, 5, Graph.Scale.Log10)

g.showGrid()
g.setAntialiasing(True)
g.replot()

gw.exportImage("sans.png", 100, False, 150)
</code>
